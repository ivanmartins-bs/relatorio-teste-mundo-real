FL-02 — Cadastro de Novo Usuário (TC-07)
Passos para reproduzir
1. Acessar a tela de cadastro.
2. Preencher Nome, E-mail, Telefone e Senha com dados válidos.
3. Tocar em CADASTRAR.
Resultado Esperado
Usuário cadastrado com sucesso e redirecionado para a tela "Minha Conta" sem exibir alertas de erro.
Resultado Obtido
Usuário era cadastrado com sucesso e redirecionado logado para a tela "Minha Conta", porém a interface exibia um popup de erro falso informando que ocorreu uma falha no cadastro.
Resolução
Correção efetuada em auth-provider.tsx alterando a inserção direta no Supabase para um método de upsert seguido de fallback com update, contornando a concorrência com a trigger de criação automática de perfil no banco de dados.
